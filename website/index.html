A KEY, NOT A CHECKBOX.

Both hands on ⌘.

Screen sharing tools ask once and remember forever. ELTransfer asks every single time, with a gesture you can’t forget you’re making. Release either key and the ghost fades within half a second.

  • Nothing sent unless the sender holds ⌘
  • Nothing shown unless the receiver holds ⌘
  • No pairing state survives a release

HONEST ABOUT THE EDGES

Still a prototype.
Here’s what that means.

ELTransfer is an experiment shared early. It tests a feeling, not a finished product. Some things you might expect are simply not there yet.

  • Not implementedBonjour discovery, pairing, encryption, multi-display mapping, real pointer handoff.
  • Hard-coded targetThe sender looks for ELTransfer.local on port 47000. Name resolution must work on your network.
  • Unsigned buildmacOS will ask you to confirm the app and to grant Accessibility and Input Monitoring.
  • Plain packetsCoordinates travel as small JSON over UDP with no authentication. Use it on networks you trust.

Small experiment.
Clear limits.

Can ELTransfer control the other Mac?

No. It sends normalized cursor coordinates and draws an overlay. It cannot move the receiving Mac’s real cursor, click, type, drag, or scroll. The overlay window ignores mouse events entirely.

Does it need the internet?

No. Both Macs need to be reachable on the same local network. There is no cloud service, no account, and no update feed in this build.

Why do both Macs need to hold ⌘?

It is a consent gesture. Holding the key means “I’m allowing this right now.” Letting go stops sending on one side and stops showing on the other. Nothing is remembered between sessions.

What does the receiver actually see?

A translucent blue circle with a white ring, about 58 pixels across while active. It appears at the proportional position of the sender’s cursor and fades to grey when packets stop arriving.

Why might macOS show a warning?

This prototype is not signed or notarized. If macOS blocks launch, right-click ELTransfer in Applications and choose Open, or allow it in System Settings → Privacy & Security. It also needs Accessibility and Input Monitoring to read the cursor position and the ⌘ key. Only open software you trust.

Is the preview above the real app?

It is an illustration of the interaction, not the macOS app. It mirrors the real behaviour: consent on both sides, activation near the edge, a proportional ghost. Nothing is sent from this page.
